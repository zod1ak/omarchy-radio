# Радио — плагин панели Omarchy

Радио прямо в строке состояния Omarchy: иконка 🎵 открывает попап со всеми
станциями Radio Record.

![preview](preview.png)

## Возможности

- **Избранное** — отдельная секция в левой колонке, всегда над историей.
  Звезда на станции добавляет её туда, звезда в секции убирает.
- **История** — последние проигранные станции, просто нажми, чтобы включить снова.
- **Поиск по названию** — над списком станций, фильтрует на лету.
- **Таймер сна** — 15/30/60 минут.
- **Случайная станция** 🎲 и **перемешивание** 🔀.
- **Усиление низких** — один клик.
- Компактный режим: только плеер, без списков.

Всё на русском. Избранное переживает перезапуск (хранится в
`~/.local/state/omarchy/world-radio-favorites.json`).

## Установка

```bash
omarchy plugin add https://github.com/zod1ak/omarchy-radio --enable
```

## Настройки

| Ключ | Тип | По умолчанию | Описание |
|---|---|---|---|
| `defaultVolume` | integer | 70 | Громкость при старте (0–130) |

## Удаление

```bash
omarchy plugin remove zero.radio
```
